Resumo da Implementação

Função gerarLinkDecisao(decisao):

  • Retorna URL ?page=formulario-elevador&id=XXX se decisao.numero_cotacao existe
  • Retorna URL ?page=dossier-obra&id=XXX se decisao.dossier_id existe
  • Retorna URL ?page=XXX&id=YYY se referencia_tabela + referencia_id existem
  • Retorna null caso nenhum campo navegável exista

Integração no DecCard:

  • Botão "Ver documento" aparece apenas se linkDocumento é não-nulo
  • Clique navega com window.location.href = linkDocumento
  • Posicionado antes de "Reprovar" e "Aprovar" (visualmente lógico)
  • Aparência: variant="outline" (botão claro e suave)
